# Support-Vector-Machines-SVM-
# Task 12: Support Vector Machines Classification

## Objective
The aim of this project is to implement Support Vector Machine classification using different kernels such as Linear, Polynomial, and RBF.

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
Social Network Ads Dataset

## Steps Performed
1. Loaded the dataset using Pandas.
2. Selected Age and EstimatedSalary as input features.
3. Applied feature scaling using StandardScaler.
4. Split the dataset into training and testing sets.
5. Trained SVM models using Linear, Polynomial, and RBF kernels.
6. Compared model performance using accuracy score.
7. Visualized the decision boundary for each kernel.

## Final Outcome
The intern understands how Support Vector Machines work, how kernels help in classification, and how to compare kernel performance.
